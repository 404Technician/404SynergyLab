# Roadmap

## v0.1.0 — Foundation (delivered)

Explainable synthetic skill/support compatibility; normalized snapshot contract; version metadata; diffs; guarded activation; regression tests; GitHub CI and upstream watcher configuration.

## v0.2.0 — First real data preview (delivered)

Eight real skills, eight supports, two conditional interactions, provenance, a repeatable nonexecuting importer, and source regression tests are delivered. The target patch remains unconfirmed for the source slice. Complete independent mechanics review before activating a verified snapshot.

## v0.2.1 — Validation review (delivered)

All sixteen factual type records were compared with public PoE2DB pages. A checksum-bound audit records the reviewed fields. Official patch notes supplied a missing sideways cascade restriction for Ice Nova + Frostbolt. Target-patch confirmation remains pending; source agreement is not live-client validation.

## v0.3.0 — Interactive lab (delivered)

Responsive browser UI with skill search, support filters, tradeoff warnings, source details, conditional skill connections, cascade context, and visible target patch/data status. Shared URLs pin the bundled snapshot and context. The snapshot identifies its engine rules version; only the current bundle is served. Unavailable historical snapshots fail visibly. Start with npm start. Sixteen browser checks run in CI; public hosting remains a future decision.

## Later

Skill-to-skill interactions, weapon requirements, resource costs, passive/unique interactions, build constraints, historical comparison, and league impact analysis. Add numerical estimates only when the required model and underlying values are verifiable.

## v0.4.0 — Conditional connections (delivered)

Sixteen skills, ten conditional interactions, two uniques, whole-setup context toggles, source description fingerprints, trigger socket type checks and an expanded 26-record source audit. Live-client validation remains pending.

## v0.30.0 — Central build check (delivered)

A single actionable report combines saved unique equipment, skill/support groups, core requirements, partial item-granted skill access and personal test scope. Conflicts and missing planned components lead to concrete next actions. Resource budgets, actual trigger paths and game performance remain explicit review/test tasks. Changed source snapshots pause the report. See [Central build check](BUILD_CHECK.md).

## v0.31.0 — Unusual interactions first (delivered)

Eight source-bound discoveries put surprising mechanics and build-defining uniques ahead of general directions and optional planners. Theme/search filters, shared reveals, full unique effects, precise event restrictions and minimal practical tests support original build creation. See [Unusual interactions](SPECIAL_INTERACTIONS.md).

## v0.32.0 — Eight more unusual discoveries (delivered)

Sixteen edited discoveries now include three minion routes and unusual projectile, Life-cost, Poison and ailment rules. A new immutable snapshot preserves the previous eight entries exactly; explicit item-granted skill requirements are checked against pinned grant mechanics. See [expanded research](SPECIAL_INTERACTIONS_EXPANSION.md).
